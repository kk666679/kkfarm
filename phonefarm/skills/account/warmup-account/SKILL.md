# Warmup Account

## Procedure

1. Start with passive browsing (1-2 days)
2. Add light interactions: likes, follows (days 3-5)
3. Post first content (day 5-7)
4. Gradually increase activity
5. Monitor for restrictions

## Anti-patterns

- Never post immediately after creation
- Never mass follow/unfollow in first week
- Never use automation flags (same timing, same content)
