# Generate Video Script

## Procedure

1. Identify hook (first 3 seconds)
2. Structure: Hook -> Value -> CTA
3. Write scene-by-scene breakdown
4. Add timing annotations
5. Include captions/overlay text
6. Suggest music/sound trends

## Anti-patterns

- Never skip the hook
- Don't make videos > 60s for short-form
- Avoid generic CTAs
