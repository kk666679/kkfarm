# Generate Post

## Procedure

1. Analyze topic and platform requirements
2. Generate text content with platform-specific formatting
3. Generate relevant hashtags
4. Create image/video prompts if needed
5. Apply brand voice guidelines
6. Validate against platform policies

## Anti-patterns

- Never reuse exact content across accounts
- Don't exceed platform character limits
- Avoid banned hashtags
